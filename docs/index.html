Fresh Music for YouTube

Control YouTube and YouTube Music from a customizable panel. Local favorites, playlists and history. Free, independent project by Necoma.

Управляй музыкой YouTube и YouTube Music с панели. Избранное, плейлисты и история хранятся локально. Без платных функций.

Optional Windows player

The free experimental Windows x64 helper is a separate install. It provides frameless always-on-top controls while music stays in the browser. WebView2 Runtime is required. Exclusive fullscreen games are not guaranteed.

Helper downloads and update channel

Required debugger access is temporary and scoped in code to the selected YouTube/Music playback/video action. Browser notices may appear. Optional cross-tab access and nativeMessaging are requested separately.
